Cara Mengubah Kode Menjadi Link Aktif (Deploy Online)

Anda dapat mempublikasikan file HTML ini menjadi link website online secara **100% Gratis** agar dapat diakses oleh siapapun dan kapanpun. Berikut pilihan metode termudah:

1 Metode Netlify Drop (Paling Mudah - Tanpa Coding)

  1. Simpan kode website ini di komputer Anda dengan nama file index.html.
  2. Buka halaman app.netlify.com/drop di browser.
  3. Drag & drop (Tarik dan lepas) file index.html Anda ke area yang disediakan.
  4. Netlify secara instan akan memberikan Link URL Aktif Website Anda yang siap dibagikan!

2 Metode GitHub Pages

  1. Buat repository baru di GitHub.com (Set Public).
  2. Upload file index.html ke repository tersebut.
  3. Masuk ke menu Settings > Pages.
  4. Pada bagian Branch, pilih main / master lalu klik Save.
  5. Tunggu 1 menit, link HTTPS website gratis Anda akan aktif.

3 Metode Vercel Drag & Drop

Buka Vercel.com, buat akun, lalu import file/repository Anda untuk mendapatkan domain kustom dan server SSL instan gratis.
